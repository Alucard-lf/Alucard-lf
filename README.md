### 🎮 Projeto em Destaque (TCC)
Atualmente, estou desenvolvendo um **jogo de terror psicológico na Unity** como meu Trabalho de Conclusão de Curso. O projeto é inspirado em títulos de suspense e simulação, focando em:
* **Narrativa Imersiva:** Exploração de roteiros que mexem com o psicológico do jogador.
* **Mecânicas de Suspense:** Desenvolvimento de sistemas de interação e ambientação opressiva.
* **Influências Literárias:** O projeto incorpora temas de vigilância e perda de privacidade, inspirados em obras como **1984** de George Orwell.
